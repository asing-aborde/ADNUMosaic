# CSDC105 AdNU Mosaic

A campus memory map web application where Ateneo de Naga University 
students and faculty can share and explore campus memories pinned by location.

## How to Run

### 1. Start the Backend (Flask)

Open terminal in backend folder:

- cd backend
- venv\Scripts\activate
- python app.py

### 2. Start the Frontend

Open `frontend/adnu-mosaic.html` with **Live Server** in VS Code 

### 3. Done
